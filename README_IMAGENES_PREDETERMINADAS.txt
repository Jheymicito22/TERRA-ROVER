COMO COLOCAR LAS FOTOGRAFIAS PREDETERMINADAS

1. Abre la carpeta imagenes/bichos/.
2. Entra en la carpeta de la provincia.
3. Coloca el JPG con el nombre EXACTO indicado abajo.
4. No agregues tildes ni cambies mayusculas/minusculas del nombre indicado.
5. No necesitas modificar index.html ni script.js.
6. El visitante NO puede cambiar las fotografías.

REGLA:
Cada ficha usa exactamente el archivo JPG indicado en datos/bichos.json.

Si cambias una fotografía, reemplaza el archivo manteniendo exactamente el mismo nombre.
