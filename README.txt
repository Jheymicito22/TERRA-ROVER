# Mapa interactivo de Áncash — Jheymi

Abre `index.html` mediante un servidor local (por ejemplo VS Code Live Server).

Estructura:
- index.html
- style.css
- script.js
- datos/plantas.json
- mapa/ancash.svg
- imagenes/ (coloca aquí quinua.jpg, papa.jpg, haba.jpg, oca.jpg y olluco.jpg)

La sección "Mapa de Áncash" usa el SVG como objeto para poder detectar los clics de sus 20 provincias sin cambiar el diseño general.

Nota: con los datos proporcionados, las 5 plantas están habilitadas inicialmente para las 20 provincias. La ficha climática provincial usa texto de referencia y los rangos climáticos de las plantas. Para datos climáticos provinciales exactos se deben cargar valores específicos por provincia.
